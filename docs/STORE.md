# My Store — ข้อมูลข้อสอบธรรมศึกษาชั้นตรี (เก็บในเครื่องเท่านั้น)

`store/` อยู่ใน `.gitignore` ทั้งหมด เพราะข้อสอบเป็นของสำนักงานแม่กองธรรมสนามหลวง repo นี้เก็บเฉพาะสคริปต์และเอกสาร
ขอบเขต: ธรรมศึกษาชั้นตรี พ.ศ. ๒๕๕๙–๒๕๖๘ (๑๐ ปี)

## แหล่งข้อมูล (ทางการ)
- ปัญหาและเฉลย PDF: https://news.gongtham.net/download-category/ข้อสอบและเฉลยย้อนหลัง/ (ดึงรายการผ่าน WordPress REST `wp-json/wp/v2/downloads`)
- ขอบข่ายหลักสูตรธรรมศึกษา ๒๕๖๔: โพสต์ id 4606 (ใช้ทำ `store/curriculum.json`)
- **ปี ๒๕๖๔ ไม่มีข้อสอบธรรมศึกษา** ในเว็บทางการ (ไฟล์ปีนั้นเป็นของนักธรรมทั้งหมด และเป็นภาพสแกน) — บันทึกเป็น `missing`

## โครงสร้าง
```
store/
├─ index.json            รายปี: สถานะ (parsed / needs_review / partial / missing), ไฟล์, ลิงก์, ผลสกัด
├─ curriculum.json       ขอบข่ายหลักสูตรตรี แยกระดับผู้สอบ/วิชา/บท/หัวข้อ
├─ raw/<ปี>/             PDF ต้นฉบับ (ปี ๒๕๖๑-๒๕๖๒ เป็น .rar -> แตกที่ raw/<ปี>/x/)
├─ years/<ปี>/exam.json  ข้อสอบรายข้อ (id, audience, subject, number, question, choices, answer, answer_source, page, needs_review)
├─ years/<ปี>/analysis.json, notes.md   สถิติและบันทึกรายปี
├─ years/2559/manual.json  ข้อที่ถอดจากภาพด้วยมือ (หน้า PDF ไม่มีชั้นข้อความ)
├─ analysis/overall.json ความถี่หัวข้อทุกปี + ข้อสอบที่ออกซ้ำข้ามปี
├─ study/<วิชา>-<ระดับ>.md  สรุปติว
└─ sheet/*.json          แถวที่ใช้นำเข้า Google Sheet
```

## ข้อมูลที่ต้องรู้
- ข้อสอบรายปีมี ๓ ระดับผู้สอบ (`primary` ประถม / `secondary` มัธยม / `adult` อุดมศึกษาและประชาชน) × ๓ วิชาปรนัย
  (`dhamma` ธรรมวิภาค, `buddha` พุทธประวัติ-อนุพุทธประวัติ, `benja` เบญจศีลเบญจธรรม) × ๕๐ ข้อ + วิชาเรียงความแก้กระทู้ธรรม (ข้อเขียน เก็บเป็นข้อความใน `essays`)
- ปี ๒๕๖๑–๒๕๖๒ มีระดับ `kson` (กศน.) เพิ่ม; ปี ๒๕๕๙–๒๕๖๐ มีชุดเดียว (`all`)
- เฉลยอ่านจากตัวหนาในไฟล์ปัญหาและเฉลย และตรวจไขว้กับตารางเฉลย/บรรทัด "เฉลยข้อ" (ปี ๒๕๕๙–๒๕๖๐)
- ข้อที่ `needs_review: true` (ตัวเลือกไม่ครบ, เฉลยไม่ชัด, ถอดจากภาพ ฯลฯ) **ไม่ถูกนำเข้าชีต** จนกว่าจะตรวจมือ
- หัวข้อ (topic) ในการวิเคราะห์เป็นการแท็กด้วยคำสำคัญ ไม่ใช่การจัดหมวดทางการ

## รันซ้ำทั้งหมด
ต้องมี: Node 20+, Python 3 + `pip install pymupdf`, `npm i`
```bash
npm run research:index        # สร้าง store/index.json
npm run research:download     # ดาวน์โหลด PDF/RAR/ZIP (ข้ามไฟล์ที่มีแล้ว)
node scripts/research/extract_rar.mjs store/raw/2561/<ไฟล์>.rar store/raw/2561/x   # ปี ๒๕๖๑, ๒๕๖๒
npm run research:curriculum   # ขอบข่ายหลักสูตร
npm run research:parse        # แยกข้อสอบ -> years/<ปี>/exam.json และอัปเดตสถานะ
npm run research:analyze      # analysis.json, notes.md, overall.json
npm run research:study        # สรุปติว + แถวชีต
node scripts/research/import_sheet.mjs --key <service-account.json> --sheet <SHEET_ID> --dry-run
```
`import_sheet.mjs` เขียนทับแท็บ subjects/questions/study/research ทั้งแท็บ — อ่านไฟล์ key จากพาธที่ส่งให้เท่านั้น ห้ามวางไฟล์ key ใน repo

## หมายเหตุลิขสิทธิ์
เมื่อนำเข้าชีตแล้ว Worker (`api/`) จะเสิร์ฟข้อสอบให้หน้าเว็บของเรา: ปฏิเสธ (403) คำขอที่ไม่มี `Origin` ตรงกับเว็บเรา/localhost,
`GET /api/questions` ไม่ส่งเฉลย/คำอธิบาย (ตัดฝั่ง Worker), เฉลยขอผ่าน `POST /api/check` ทีละข้อที่ตอบแล้ว และจำกัดอัตราต่อ IP
นี่เป็นเพียงการยับยั้งการดึงข้อมูลเป็นชุด (header ปลอมได้, วนเรียก check ทีละข้อได้) ไม่ใช่การยืนยันตัวตน — เว็บที่ให้ผู้ใช้ทำข้อสอบได้ย่อมส่งข้อสอบถึงเบราว์เซอร์อยู่แล้ว
หน้าเว็บมีเครดิตแหล่งข้อสอบ/คำปฏิเสธที่ท้ายหน้า และ README ระบุช่องทางแจ้งให้ถอดเนื้อหา

## ชุดติว/สอน ระดับมัธยม (`store/study/secondary/`) — เก็บในเครื่องเท่านั้น
สรุปโดยผู้เขียนจาก **หนังสือธรรมศึกษา ชั้นตรี ระดับมัธยมศึกษา พ.ศ.๒๕๖๔** (แม่กองธรรมสนามหลวง) ไม่คัดลอกข้อความตำรา และควรให้ผู้รู้ตรวจก่อนเผยแพร่

```
store/study/secondary/
├─ src/<วิชา>/ch*.json     ต้นฉบับที่เขียนมือ: บท → หัวข้อ → หัวข้อย่อย → ประเด็น/ศัพท์/คำสำคัญ/แฟลชการ์ด/ตัวช่วยจำ + หน้าอ้างอิง
├─ tree.json               ต้นไม้เนื้อหารวม (ธรรมวิภาค / อนุพุทธประวัติและศาสนพิธี / เบญจศีลเบญจธรรม / เรียงความแก้กระทู้ธรรม)
├─ md/<วิชา>.md            อ่านง่าย พร้อมจำนวนข้อสอบที่เกี่ยวข้องต่อหัวข้อย่อย
├─ flashcards.json         แฟลชการ์ดทั้งหมด (ผูกกับหัวข้อย่อย)
├─ question_map.json       ข้อสอบมัธยมทุกข้อ → หัวข้อย่อย + คำอธิบายเฉลย + ระดับหลักฐาน (evidence)
├─ coverage.md             ความครอบคลุมรายวิชา/รายปี และตัวอย่างข้อที่ยังจับคู่ไม่ได้
├─ essay_history.json      กระทู้ธรรมที่ออกสอบรายปี (ระดับมัธยม)
├─ book_pages.json, book.txt  ข้อความหนังสือเรียนที่สกัดแล้ว (อ้างอิงเวลาเขียนเพิ่ม)
└─ gaps_2565plus.json      ข้อปี ๒๕๖๕-๒๕๖๘ ที่หลักฐานในสรุปยังไม่ครบ (ใช้เป็นรายการเติมเนื้อหา)
```

ระดับหลักฐานของคำอธิบายเฉลย: `answer-in-notes` = ข้อความเฉลยปรากฏในสรุปหัวข้อย่อย / `topic-only` = จับหัวข้อได้แต่เป็นข้อประยุกต์ ยังไม่มีในสรุป / `none` = นอกตำราฉบับ ๒๕๖๔ (มักเป็นหลักสูตรเดิมปี ๒๕๖๑-๒๕๖๓)

```bash
python scripts/research/extract_book.py          # สกัดข้อความหนังสือเรียน (ต้อง npm run research:curriculum ก่อน)
python scripts/research/build_secondary_study.py # รวมต้นไม้ + จับคู่ข้อสอบ + คำอธิบายเฉลย + md
python scripts/research/essay_history.py         # สถิติกระทู้ธรรมรายปี
```
